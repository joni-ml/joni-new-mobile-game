# 🔎 בדיקת הבדיקות — גרסה עצמאית

הגרסה הזו עומדת בפני עצמה. היא לא מתערבבת עם שאר העבודה, ואני לא נוגע
בה בזמן שאתה עובר על הבדיקות — ככה מה שאתה שופט היום עדיין יהיה שם מחר.

## איך פותחים
פותחים את `index.html` → ⚙️ הגדרות → **🔎 בדיקת הבדיקות**

והציור נשמר עם הבדיקה ונכנס לדוח.

לבדיקה הראשונה שעוד לא שפטת. אפשר גם לקפוץ לכל מספר.

## הדוח
`🏁 סיום` → `📋 להעתיק הכל` → לשלוח לי.

- מה שסימנת **נכון** = שורה אחת
- מה שסימנת **לא נכון** = מה נמדד, מה היה אמור, והציור שלך

הציור נשמר כרשת מכווצת עם מקרא:

```
מקרא: 1=אבן  2=מים
  y8   4-22:1        ← שורה 8, עמודות 4 עד 22, חומר 1 (אבן)
  y9   4-9:1 10:2    ← עמודות 4-9 אבן, עמודה 10 מים
```

תאי אוויר לא נכללים, כדי שהדוח יישאר קצר.
