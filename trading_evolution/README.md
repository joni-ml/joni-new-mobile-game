# אבולוציה של בוטי מסחר במטבעות דיגיטליים (כסף מזויף)

כל בוט מתחיל עם 5 ש"ח וירטואליים, מטבע אחד שהוא סוחר בו (ביטקוין, את'ריום, דוג'קוין ועוד), ואסטרטגיה משלו.
כל כמה זמן הבוטים משלמים לך אחוז מהכסף שלהם, וכל כמה זמן יש **מבחן**:
- החצי הפחות טוב מת, והכסף שלו עובר אליך.
- כל בוט מהחצי הטוב **מחליט בעצמו** אם להשתכפל. לכל בוט יש כלל משלו, למשל
  "משתכפל רק אם הרוויח לפחות 3% מאז המבחן, ושלכל חצי יישארו לפחות 1.50 ש\"ח".
- מי שמשתכפל מתחלק בכסף שלו עם השכפול. השכפול מקבל אסטרטגיה דומה עם שינוי קטן (גם בכלל השכפול),
  ולפעמים עובר לסחור במטבע אחר.
- מי שבוחר לא להשתכפל שומר את כל הכסף שלו, אבל אז יש פחות בוטים, ורק הוא נושא את האסטרטגיה שלו.
- אם אחרי מבחן נשארו פחות בוטים מ-`start_bots`, נולדים בוטים חדשים במקומות הריקים, מהאסטרטגיות של הבוטים
  הכי טובים. על כל בוט חדש אתה שם עוד `start_money`, כמו בהתחלה (אפשר לכבות עם `refill = false`).

ככה האסטרטגיות מתפתחות, והאבולוציה מגלה בעצמה באיזה מטבע הכי קל להרוויח.

**המטרה של הבוטים** (`goal` בהגדרות): כברירת מחדל (`"hold"`) הם מנסים להחזיק את המטבע כמה שיותר זמן,
ומוכרים רק כשהם רואים סכנה: הציון שלהם יורד מתחת ל"קו הסכנה", או שהמחיר נופל הרבה מהשיא מאז שקנו.
אחרי שברחו הם מחכים כמה נרות, וכשהסכנה עוברת קונים שוב. הם אף פעם לא מוכרים רק כי הרוויחו.
מה נחשב סכנה, ולאילו שיטות להקשיב, האבולוציה מגלה בעצמה. `goal = "trade"` מחזיר את המסחר הרגיל.

כתוב ב-Python (צריך גרסה 3.11 ומעלה), בלי ספריות חיצוניות.

## ההגדרות: `settings.toml`
פותחים עם Notepad (או כל עורך טקסט) ומשנים:
- `assets`: באילו מטבעות לסחור
- `start_bots` / `max_bots`: כמה בוטים בהתחלה, וכמה לכל היותר באותו זמן
- `pay_every` / `pay_percent`: כל כמה זמן הבוטים משלמים לך, וכמה אחוזים
- `select_every` / `kill_percent`: כל כמה זמן יש מבחן, וכמה אחוזים מתים בו
- `losers_money`: לאן הולך הכסף של מי שמת: אליך (`"me"`) או לבוטים ששרדו (`"winners"`)
- `candle`: כל כמה זמן מגיע מחיר חדש במסחר החי (`1m` / `5m` / `15m` / `1h`)
- `signals`: באילו שיטות הבוטים יכולים להשתמש כדי להחליט מתי לקנות ומתי למכור:
  מגמה, RSI, תנופה, מרחק מהממוצע, MACD, רצועות בולינגר, ערוץ 20 נרות, פריצה של 55 נרות (שיטת הצבים),
  כמה השוק סוער, וזיכרון דפוסים ("מה קרה בעבר אחרי ש-5 הנרות האחרונים נראו ככה"),
  ו-6 גלאים מהאינטרנט: פחד וחמדנות בקריפטו, פחד וחמדנות בבורסה האמריקאית (CNN), מדד הפחד VIX,
  כמה אנשים קוראים על ביטקוין בוויקיפדיה, כמה הרשת של המטבע פעילה, וכמה המטבע יקר (MVRV).
  הגלאים מתעדכנים לבד פעם ב-6 שעות במסחר החי, והבוטים משתמשים רק במספר של אתמול (של היום עוד לא פורסם).
  כל בוט נותן לכל שיטה משקל משלו, והאבולוציה מגלה אילו שיטות עוזרות.

זמנים כותבים ככה: `30m` = חצי שעה, `6h` = שש שעות, `1d` = יום, `1w` = שבוע.
אם משנים את הקובץ בזמן ש-`live.py` רץ, השינוי נכנס לתוקף בבדיקה הבאה.

## שלב 1: להוריד מחירים אמיתיים
```
python fetch_data.py            # מחיר יומי של כל מטבע מההתחלה עד היום
python fetch_data.py --recent   # גם מחיר לשעה של השנתיים האחרונות (מ-Binance)
```

## שלב 2: לנסות על העבר
```
python evolution_sim.py                                     # כל התקופה
python evolution_sim.py --from 2018-06-01 --split 2022-01-01
```
עם `--split` הבוטים מתאמנים על התקופה שלפני התאריך, והאסטרטגיות הכי טובות נשמרות ב-`brains.json`.
אחר כך הן נבחנות על התקופה שאחרי, שהן לא ראו, מול בוטים שלא התאמנו בכלל.

## שלב 3: מסחר חי על נייר
```
python live.py            # מחירים אמיתיים מ-Kraken / Binance / Coinbase
python live.py --status   # מה המצב עכשיו
python live.py --reset    # להתחיל מאפס
```
**אין כאן שום כסף אמיתי:** הקוד רק קורא מחירים מהבורסה, בלי חשבון ובלי מפתחות.
המצב נשמר ב-`live_state.json`, אז אפשר לעצור עם Ctrl+C ולהמשיך אחר כך מאותה נקודה.

## לראות את הבוטים
- `evolution_sim.py` יוצר את הדף `dashboard.html`.
- `live.py` מעדכן את הדף `live_dashboard.html`, והדף מתרענן לבד כל חצי דקה.

פותחים את הדף בדפדפן (לחיצה כפולה). יש בו:
- **חלון לכל בוט**: כמה כסף יש לו, גרף קטן של הכסף שלו, באיזה מטבע הוא סוחר, כמה שילם לך ומה האסטרטגיה שלו
- **"איך הוא מחליט אם לקנות או למכור"** (לוחצים בתוך החלון של הבוט): מה הבוט מדד עכשיו בכל אחד מ-4 הסימנים,
  כמה כל סימן תרם לציון, גרף של הציון לאורך הזמן עם הקווים שמעליהם הוא קונה ומתחתם הוא מוכר,
  הכללים שלו (סטופ-לוס, לקיחת רווח), ומה הוא עשה לאחרונה ולמה
- כמה כסף הרווחת או הפסדת, לעומת מה שהיה קורה אם היית קונה את המטבעות ומחכה
- כמה כל מטבע עלה או ירד
- מה קרה לאחרונה: מי מת, מי שוכפל ומה יצא בכל מבחן

## הקלטה: הבוטים בפעולה
```
python replay.py                                   # השנה האחרונה שיש לה מחירים
python replay.py --from 2024-01-01 --to 2025-01-01
```
הבוטים סוחרים יום אחרי יום על מחירים אמיתיים, עם כל השיטות והחושים מהאינטרנט ועם ההגדרות שלך,
והדף `replay.html` מנגן את זה כמו סרטון: כפתור נגן/עצור, פס זמן ומהירות. כדי לראות בטלפון: `python phone.py replay.html`.

## לראות בטלפון
```
python live.py --phone     # מסחר חי, והדף נפתח גם בטלפון
python phone.py            # רק להראות בטלפון את הדף האחרון, בלי לסחור
```
התוכנה מדפיסה כתובת כמו `http://192.168.1.23:8000`. פותחים אותה בדפדפן של הטלפון, כשהטלפון מחובר **לאותו Wi-Fi** כמו המחשב.
- בפעם הראשונה ווינדוס ישאל אם לאפשר ל-Python גישה לרשת: לוחצים "אפשר" (Allow).
- המחשב צריך להישאר דלוק ולא להיכנס למצב שינה.
- מהטלפון אפשר לראות רק את הדף. ההגדרות והקבצים האחרים לא נגישים.
