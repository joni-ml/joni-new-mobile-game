# אבולוציה של בוטי מסחר (סימולציה על נייר)

כל בוט מתחיל עם 5 ש"ח וירטואליים ואסטרטגיה אקראית. בסוף כל יום הבעלים לוקח ממנו אחוז.
בוט שהכסף שלו נגמר מת, ובמקומו נולד בוט חדש. בוט שהרוויח במשך שבוע משוכפל: חצי מהכסף שלו עובר לצאצא עם מוטציה קטנה.

```bash
python3 evolution_sim.py                       # 60 ימים עם מחירים מדומים
python3 evolution_sim.py --days 90 --seed 7    # תרחיש אחר
python3 evolution_sim.py --cut 0.02            # הבעלים לוקח 2% ביום
python3 evolution_sim.py --csv btc_hourly.csv  # מחירים אמיתיים (עמודה close)
```

בסיכום תראו כמה השקעתם, כמה לקחתם מהבוטים, כמה כסף עוד נשאר בתוכם ומה הרווח או ההפסד הנקי.
הסימולציה לא משתמשת בכסף אמיתי ולא מתחברת לשום בורסה.
