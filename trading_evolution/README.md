# אבולוציה של בוטי מסחר בביטקוין (כסף מזויף)

כל בוט מתחיל עם 5 ש"ח וירטואליים ואסטרטגיה משלו. כל יום הבעלים לוקח ממנו אחוז מהכסף.
בוט שהכסף שלו נגמר מת. בוט שהרוויח במשך שבוע משוכפל, וחצי מהכסף שלו עובר לצאצא.

**איך האסטרטגיות מתפתחות:** כל בוט מחליט מתי לקנות לפי 4 סימנים: מגמה, ירידה חדה, תנופה, ומרחק מהממוצע.
כל בוט נותן משקל אחר לכל סימן. כשבוט מת, הבוט החדש שבא במקומו הוא בדרך כלל "ילד" של שני בוטים מצליחים:
הוא מקבל חלק מהתכונות מכל הורה, ועוד שינוי קטן. רק 15% מהבוטים החדשים נולדים עם אסטרטגיה אקראית לגמרי,
כדי שתמיד יהיו גם רעיונות חדשים.

כתוב ב-Python 3, בלי ספריות חיצוניות.

## שלב 1: להוריד מחירים אמיתיים
```bash
python3 fetch_data.py            # מחיר יומי 2010 עד היום + מחיר לשעה 2011-2017
python3 fetch_data.py --recent   # גם מחיר לשעה של השנתיים האחרונות (מ-Binance)
```

## שלב 2: אימון ומבחן על העבר
```bash
python3 evolution_sim.py --data data/btc_daily.csv --from 2016-01-01 --split 2022-01-01
```
הבוטים מתאמנים על 2016-2021, והאסטרטגיות הכי טובות נשמרות ב-`brains.json`.
אחר כך הן נבחנות על 2022 עד היום, תקופה שהן לא ראו, מול בוטים שלא התאמנו בכלל.

## שלב 3: מסחר חי על נייר
```bash
python3 live.py            # מחירים אמיתיים מ-Kraken / Binance / Coinbase, כל 10 דקות
python3 live.py --status   # מה המצב עכשיו
```
הבוטים מתחילים מהאסטרטגיות של `brains.json` וממשיכים להתפתח. כל יום מודפסת שורה אחת של סיכום.
המצב נשמר ב-`live_state.json`, אז אפשר לכבות את המחשב ולהמשיך מאותה נקודה.
**אין כאן שום כסף אמיתי:** הקוד רק קורא מחירים מהבורסה, בלי חשבון ובלי מפתחות.

## גרפים
כל הרצה של `evolution_sim.py` יוצרת את הקובץ `chart.html`, ו-`live.py` מעדכן את `live_chart.html` פעם ביום.
פותחים אותם בדפדפן (לחיצה כפולה). בדף יש:
- כמה כסף הרווחת או הפסדת לאורך הזמן, לעומת מה שהיה קורה אם היית קונה ביטקוין באותו כסף
- מחיר הביטקוין באותה תקופה
- טבלה עם כל המספרים

## הגדרות שימושיות
- `--cut 0.001` - כמה הבעלים לוקח כל יום (ברירת המחדל: 1%, וזה הרבה מאוד. בוט צריך להרוויח 1% כל יום רק כדי לא להתכווץ).
- `--bots 20` - כמה בוטים בהתחלה.
- `--verbose` - להראות כל מוות ושכפול.
