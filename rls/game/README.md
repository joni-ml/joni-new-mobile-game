# 📁 game — הקוד של המשחק

**כאן נמצא כל הקוד של RLS. רק קוד — בלי בדיקות, בלי מסמכים.**

| קובץ | מה זה | שורות |
|---|---|---|
| `chem.js` | מנוע הכימיה: היסודות, החומרים, וחוק התגובה היחיד | 315 |
| `matter.js` | תכונות פיזיקליות שנגזרות מהכימיה: צפיפות, קיבול חום, מוליכות, חום כמוס, צבע | 101 |
| `world.js` | שכבת הרשת: תאים, כובד, תמיכה, זרימה, חום, ותגובות בין שכנים | 429 |

בהמשך ייכנס לכאן גם הממשק.

## איך הם מסתדרים

```
chem.js      אילו אטומים, ומה קורה כשהם נפגשים
   ↓
matter.js    מה המשמעות הפיזיקלית של האטומים האלה
   ↓
world.js     איך זה נראה על מסך של תאים
```

החץ הולך רק לכיוון אחד. `chem.js` לא יודע שיש רשת, ו-`matter.js` לא יודע
שיש כובד. לכן אפשר לשנות את המשחק בלי לגעת בכימיה.

---

הבדיקות והמסמכים נמצאים **תיקייה אחת למעלה**, ב-`rls/`.
