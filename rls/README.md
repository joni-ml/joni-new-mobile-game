# RLS — Real Life Simulator

התחלה מחדש. לא המשך של ארגז חול — **ארכיטקטורה אחרת מהשורה הראשונה.**

## הרעיון

במשחק הקודם לכל זוג חומרים היה חוק ידני משלו. 60 פונקציות תגובה.
כל חומר חדש דרש לכתוב עוד N חוקים, וכל חוק שנשכח היה באג — הבאג של
"מים לא עוברים מחול לאדמה" היה בדיוק זה: אף אחד לא כתב את החוק ההוא.

כאן אין חומרים מקודדים. **יש אטומים, ויש חוק אחד.**

תא מחזיק *אילו אטומים יש בו*. כששני תאים נפגשים, החוק בודק אם סידור מחדש
של האטומים משחרר אנרגיה. אם כן, והטמפרטורה מספיקה — זה קורה.

זה הכל. כל התגובות למטה נובעות מהחוק הזה. **אף אחת מהן לא כתובה בשם בשום מקום.**

## מה זה מייצר בפועל

```
2H₂ + O₂        →  2H₂O                    משחרר 572 kJ
CH₄ + 2O₂       →  2H₂O + CO₂              משחרר 891 kJ
Fe₂O₃ + 2Al     →  2Fe + Al₂O₃             משחרר 852 kJ   ← תרמיט
2Na + Cl₂       →  2NaCl
2Mg + CO₂       →  C + 2MgO                ← מגנזיום בוער בלי חמצן
C + O₂          →  CO₂                      משחרר 394 kJ
```

ומה שלא קורה, וגם זה נובע מאותו חוק:

```
H₂O + H₂O       →  כלום        מים לא מתפרקים מעצמם
Au + O₂         →  כלום        זהב לא מחמצן
H₂ + O₂ בקור    →  כלום        צריך חום כדי להתחיל
N₂ + O₂ בחדר    →  כלום        אוויר רגיל אינרטי
```

## התכונה החשובה ביותר

**שימור חומר לפי בנייה, לא לפי זהירות.**

החיפוש שוקל אך ורק חלוקות ששומרות בדיוק את אותם אטומים. לכן אי אפשר
ליצור או למחוק חומר — גם אם נכתוב באג מעל. במשחק הישן זה היה מקור לחצי
מהבאגים: מים שנעלמו בסיבוב מסך, קצף שמחק חומר, חימום שהשמיד 90% מהמים.
כאן זה **לא יכול לקרות**.

נבדק: 509 תגובות, 0 הפרות.

## למה זה מהיר מספיק לטלפון

חישוב "מה A ו-B יעשו ב-T מעלות" יקר. אבל **התשובה לעולם לא משתנה.**
אז מחשבים פעם אחת ושומרים.

```
חישוב ראשון:  320ms על 2,209 צירופים
אחרי שנשמר:   0.3ms          ← פי 1,067 מהר יותר
```

מהפעם השנייה זו קריאה ממפה — בדיוק מהיר כמו ה-switch הישן, רק בלי 60
הפונקציות.

## איך מוסיפים כימיה

**לא כותבים קוד.** מוסיפים שורה ל-`KNOWN`:

```js
'CaCO3': {name:'אבן גיר', dHf:-1207, melt:825, boil:825, col:[228,222,205], st:'solid'},
```

`dHf` הוא אנתלפיית ההיווצרות — כמה החומר יציב. זה המספר היחיד שמחליט.
כל התגובות שהחומר הזה משתתף בהן ייגזרו מעצמן.

## מה עוד המנוע עושה לבד

**מייצר חומרים שאיש לא רשם.** אם נשארים אטומים שמסתדרים לפי ערכיות,
נוצרת תרכובת חדשה עם תכונות משוערות. התחלנו עם 47 חומרים בטבלה, ובסריקה
אחת נוצרו 147.

תרכובת מנוחשת חייבת להתאזן לפי ערכיות — אחרת נרשמו 19,000 חומרים כמו
`HN3` שאינם קיימים, וזה גם ניפח את הזיכרון.

## מגבלות — בכנות

- זה **קירוב** של תרמודינמיקה, לא כימיה קוונטית. חיזוי תגובות אמיתי הוא
  בעיה פתוחה במחקר.
- אנרגיית השפעול היא נוסחה פשוטה, לא ערך נמדד לכל תגובה.
- תרכובות מנוחשות מקבלות תכונות משוערות ומסומנות `derived:true`.
- שלישיות יסודות נתמכות רק אם הן ב-`KNOWN`.
- **חיים לא יצמחו מזה.** הכימיה כן אמיתית.
