# משרד ראש הממשלה 🏛️ — יחיד ומרובה משתתפים

משחק סימולציה פוליטית: בוחרים מדינה ומנהלים אותה רבעון אחר רבעון — משברים,
תקציב, בחירות, יריב פוליטי, שרים וכישורים.

בכניסה בוחרים איך לשחק:

- **👤 משחק יחיד** — בדיוק כמו המשחק המקורי. שאר מדינות העולם מנוהלות על ידי המחשב.
- **🌍 משחק מרובה משתתפים** — **המכשיר שלך מארח את המשחק**. אתה מקבל מספר חדר
  דו-ספרתי, חברים מכל העולם מצטרפים איתו, וכל אחד מנהל מדינה אחרת. רואים אחד את
  השני חי במסך "🌍 מה קורה בעולם", וסוחרים, עוזרים, מטילים סנקציות ומרגלים בזמן אמת.

> הקוד של המשחק המקורי לא שונה כלל. כל התוספת עטופה סביבו (מסך בחירה + שכבת רשת),
> כך שמצב "שחקן יחיד" מתנהג בדיוק כמו קודם.

## איך משחקים לבד

פותחים את `index.html` בדפדפן ובוחרים "👤 משחק יחיד". לא צריך שום דבר נוסף.

## איך משחקים עם אנשים

### איך זה בנוי

הטלפון של מי שפתח את החדר הוא **המארח** — החדר, השחקנים והמצב חיים אצלו במכשיר,
והמידע זורם **ישירות בין המכשירים** (WebRTC). כשהמארח יוצא, החדר נסגר.

צריך רק "שדכן" קטן שמכיר בין המכשירים בפעם הראשונה (מחליף כתובות). המשחק משתמש
בשירות הציבורי והחינמי של PeerJS לזה. **הוא לא רואה את המשחק ולא מעביר אותו** —
רק את ההיכרות הראשונית.

### מה שצריך פעם אחת: להעלות את המשחק לאינטרנט

זה החלק היחיד שדורש הכנה. הדפדפן חוסם חיבורים כאלה כשהקובץ נפתח כקובץ מקומי,
ולכן **המשחק חייב להיפתח מכתובת `https://`** (הקבצים עצמם — לא המשחק).

**הדרך הפשוטה — GitHub Pages:**

1. ב-GitHub: `Settings` → למטה `Danger Zone` → `Change visibility` → **Public**
   (Pages בחשבון חינמי עובד רק על repo ציבורי).
2. `Settings` → `Pages` → תחת `Source` בוחרים `Deploy from a branch`,
   בוחרים את הענף ואת `/ (root)` → `Save`.
3. אחרי דקה-שתיים המשחק יהיה בכתובת:
   `https://<שם-המשתמש>.github.io/joni-new-mobile-game/prime-minister/`

**אם רוצים שה-repo יישאר פרטי:** אפשר להעלות את התיקייה `prime-minister` לכל
אירוח סטטי חינמי (למשל Netlify Drop) ולקבל כתובת `https` משלכם.

### ואז — פשוט משחקים

1. כולם פותחים את הכתובת בטלפון ובוחרים "🌍 משחק מרובה משתתפים".
2. אחד לוחץ **"🆕 צור שרת"** ומקבל **מספר חדר בגדול** (למשל `59`).
3. השאר מקלידים את המספר ולוחצים **"🔗 התחבר לחבר"**.
4. המארח (מסומן 👑) רואה את כולם נכנסים לחדר ההמתנה, ולוחץ **"▶️ התחל משחק"**
   כשכולם שם. כולם עוברים יחד לבחירת המדינות.
5. כל אחד בוחר מדינה **אחרת** — מדינה תפוסה מסומנת "נתפס ע"י <שם>".

אם המארח מתנתק, הכתר 👑 עובר אוטומטית לשחקן אחר שנשאר.

## מה קורה בין שחקנים אמיתיים

### רבעונים משותפים
כל השחקנים תמיד באותו רבעון. מי שבחר ראשון רואה "ההחלטה שלך נשלחה" ואת רשימת מי
שעוד לא סיים, וכולם עוברים לרבעון הבא יחד. שחקן שהתנתק או שהודח לא מעכב אף אחד.

### פעולות מול שחקן — הוא מחליט, לא המערכת
מול בוט הפעולה פשוט קורית. מול אדם היא נשלחת כ**הצעה שהוא עונה עליה**:

| פעולה | מה הוא מקבל |
|-------|--------------|
| 🤝 סחר | לחתום / לדחות |
| 📦 סיוע | לקבל / לסרב |
| ⛔ סנקציות | לספוג · סנקציות נגד (שניכם נפגעים) · פנייה דיפלומטית (הנזק מרוכך) |
| 🕵️ ריגול | לחשוף ולגרש / לטפל בשקט |

עד שהוא עונה — **שום דבר לא מוחל על אף צד**. שני הצדדים מקבלים הודעה עם התוצאה.

### ⚔️ מלחמה
במסך "מה קורה בעולם" יש כפתור מלחמה על כל מדינה שמנוהלת בידי אדם. המגן בוחר:

- **להתבצר בהגנה** — מחזק אותו משמעותית
- **מתקפת נגד** — מחליש את התוקף וגם אותו
- **לבקש הפסקת אש** — התוקף מחליט: להסכים (נגמר בלי הרוגים) או לסרב (והמגן נלחם מעמדה חלשה)

הכוח נקבע לפי מוכנות צבאית, יציבות ואישור ציבורי, עם מזל.
**המפסיד מודח — המשחק שלו נגמר.** המנצח מקבל זינוק באישור הציבורי.

### 🕊️ האו"ם
כפתור "האו"ם" בשורת הכפתורים פותח הצעת החלטה נגד כל מדינה. עלות: 600 מיל' ₪,
הצעה אחת לרבעון.

| הצעה | מה קורה אם עוברת |
|------|------------------|
| ⛔ **סנקציות בינלאומיות** | היעד סופג -2500 קופה, -12 אישור, -8 יציבות. היחסים של כולם איתו קורסים |
| ⚛️ **אישור לתקיפה גרעינית** | המציע מקבל אישור חד-פעמי לשגר על אותה מדינה |

**שחקנים אמיתיים מצביעים בעצמם.** שאר מדינות העולם מצביעות לפי היגיון, לא לפי
מזל — הן קוראות את היעד כמו משרד חוץ:

- מתיחות גבולות גבוהה → נוטות **בעד**
- משטר מבודד ולא פופולרי → נוטות **בעד**
- שותפת סחר עשירה → נוטות **נגד** (אינטרס כלכלי)
- מדינה מצביעה לא יציבה בעצמה → נמנעת מעימות

מסך התוצאה מציג את הספירה ואת **הנימוק הרווח באולם**.

**הרף לגרעין גבוה בכוונה:** מדינה רגילה לא תאשר שימוש בנשק גרעיני בשום רמת
מתיחות. צריך יעד שנמצא *גם* על סף מלחמה (מעל 88% מתיחות) *וגם* מבודד לגמרי בבית.
שיגור בלי אישור נחסם. שיגור עם אישור מדיח את היעד — ועולה למשגר -20 אישור,
-15 יציבות ו-50 נקודות יחסים מול כל העולם.

### נקודות
כל רבעון מזכה ב-**2 נקודות ניסיון** (במקום 1), להשקעה בעץ הכישורים.

## ⏱ שעון הרבעון

לכל רבעון יש **חמש דקות**. השעון יושב מתחת לשורת הרבעון ונצבע באדום בדקה האחרונה.

**המדינה לא עוצרת בזמן שאת/ה חושב/ת.** כל שנייה משלמת פרוסה מהבסיס הרבעוני —
הקופה נעה, האינפלציה שוחקת את האישור, והאריחים מתעדכנים חיים. מה שהשעון כבר
שילם נרשם, וההתחשבנות בסוף התור משלמת רק את היתרה — אף פעם לא כפול.

אם הזמן אוזל, **הקבינט מחליט במקומך** — בוחר את האפשרות הבטוחה ביותר על השולחן,
ועולה לך 5 נקודות אישור. במצב מרובה משתתפים השעון נעצר בזמן שממתינים לשאר.

בכל כרטיס במסך "מה קורה בעולם" יש כפתור **⚔️ הכרז מלחמה** — לא רק על שחקנים

כשזה קורה — יש לך שלוש תשובות אמיתיות: **להתבצר** (מחזק מאוד בקרב, יקר),

## בדיקות

```bash
npm start                                  # מגיש את המשחק על :8080
npx peer --port 9000 --host 127.0.0.1      # שדכן מקומי, לחבילת המולטיפלייר
npm test                                   # מריץ את ארבע החבילות (76 בדיקות)
```

`tests/warfare.test.js` בודק את שעון הרבעון, המדדים החיים, פיקוד הצבא והמלחמות.
`tests/mechanics.test.js` בודק את עמדת הקבינט, פנקס הסיבתיות ותור ההשלכות.
`tests/effects.test.js` בודק את בקרת האפקטים ואת הנאום הלאומי.
`tests/multiplayer.test.js` בודק הצעות בין שחקנים, רבעונים משותפים ומלחמה בין אנשים.
שתיהן מריצות את המשחק האמיתי בדפדפן אמיתי.

> כל החוקים האלה יושבים ב-`mp-room.js` בלבד — גם החיבור הישיר וגם שרת ה-Node
> מריצים את אותו ספר חוקים, כך שאין שתי התנהגויות שונות.

## אופציונלי: שרת Node משלכם

מי שמעדיף שרת מרכזי במקום חיבור ישיר, יכול להריץ את `server.js`:

```bash
npm install
npm start          # http://localhost:8080
```

ואז במסך המולטיפלייר ללחוץ "⚙️ כתובת שרת" ולהקליד את כתובת השרת
(למשל `ws://localhost:8080`). **רק כתובת `ws://` או `wss://` תקינה** מפעילה את
המסלול הזה; אם השדה ריק, המשחק תמיד ישתמש בחיבור הישיר בין המכשירים.

אפשר גם להחליף את שרת השידוך, אם הציבורי לא זמין — מגדירים לפני טעינת המשחק:

```html
<script>window.MP_PEER_CONFIG = { host:'my-peer-server.com', port:443, path:'/', secure:true };</script>
```
