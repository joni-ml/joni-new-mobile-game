# משרד ראש הממשלה 🏛️ — יחיד ומרובה משתתפים

משחק סימולציה פוליטית: בוחרים מדינה ומנהלים אותה רבעון אחר רבעון — משברים,
תקציב, בחירות, יריב פוליטי, שרים וכישורים. עכשיו אפשר לשחק גם **יחד עם
שחקנים אמיתיים מכל העולם**.

כשנכנסים למשחק בוחרים:

- **👤 משחק יחיד** — בדיוק כמו המשחק המקורי. שאר מדינות העולם מנוהלות על ידי המחשב.
- **🌍 משחק מרובה משתתפים** — כמה שחקנים מתחברים לאותו "חדר", כל אחד מנהל מדינה
  אחרת, ורואים אחד את השני חי במסך "🌍 מה קורה בעולם". אפשר לסחור, לשלוח סיוע,
  להטיל סנקציות ולרגל אחד על השני — בזמן אמת.

> הקוד של המשחק המקורי לא שונה. כל תוספת המולטיפלייר עטופה מסביב לו (מסך בחירה +
> שכבת רשת), כך שמצב "שחקן יחיד" מתנהג בדיוק כמו קודם.

---

## איך משחקים לבד

פשוט לפתוח את הקובץ **`index.html`** בדפדפן ולבחור "👤 משחק יחיד". לא צריך כלום נוסף.

## איך משחקים יחד (מרובה משתתפים)

למשחק משותף צריך **שרת אחד** שכולם מתחברים אליו. מספיק שאדם אחד יריץ אותו.

### 1. הפעלת השרת

צריך [Node.js](https://nodejs.org) מותקן. בתוך תיקיית `prime-minister`:

```bash
npm install
npm start
```

יופיע:

```
🌍  משרד ראש הממשלה — השרת פועל
    שחק/י כאן:            http://localhost:8080
```

### 2. התחברות

- **על אותו מחשב:** פותחים `http://localhost:8080`, בוחרים "🌍 משחק מרובה משתתפים",
  ומשאירים את כתובת השרת `ws://localhost:8080`.
- **חברים באותה רשת (בית/כיתה):** מגלים את כתובת ה-IP של המחשב שמריץ את השרת
  (למשל `192.168.1.20`), וכל אחד נכנס לדפדפן אל `http://192.168.1.20:8080`.
- **חברים מכל העולם 🌍:** מעלים את השרת לאירוח חינמי (Render / Railway / Glitch /
  Fly.io וכו'). מקבלים כתובת כמו `https://my-game.onrender.com`, נכנסים אליה,
  ובוחרים "🌍 משחק מרובה משתתפים". כתובת השרת תזוהה אוטומטית.

### 3. לשחק

1. כולם מזינים **שם** ו**אותו קוד חדר** (למשל `friends1`) ולוחצים "התחבר".
2. רואים מי בחדר, לוחצים "בחר/י מדינה ←" ובוחרים כל אחד מדינה **פנויה** אחרת.
3. במהלך המשחק, כפתור "🌍 מה קורה בעולם" מראה את המדינות של החברים בזמן אמת —
   שם אפשר לסחור, לעזור, להטיל סנקציות ולרגל.

## קבצים

| קובץ | תיאור |
|------|-------|
| `index.html` | המשחק המלא (יחיד + מרובה משתתפים) |
| `server.js` | שרת המולטיפלייר (מגיש את המשחק + WebSocket) |
| `package.json` | הגדרות והתלות היחידה (`ws`) |

## פרטים טכניים

- השרת שומר את מצב החדרים בזיכרון בלבד (נמחק כשהשרת נכבה) — פשוט ומהיר למשחק עם חברים.
- כל שחקן משדר "תקציר מדינה" (אישור, יציבות, מתיחות, קופה, חוב) לשאר, וכל פעולה
  דיפלומטית מועברת ישירות לשחקן היעד.
- אם שחקן מתנתק, המדינה שלו חוזרת להיות מנוהלת אוטומטית על ידי המחשב.
