# 🏖️ ארגז חול (Sandbox)

משחק **ארגז חול** לניסויים בפיזיקה — בהשראת *The Sandbox*.
בונים עולם מחומרים (חול, מים, אבן, עץ), ומשחקים עם פיזיקה: הכובד מפיל חול,
מים זורמים, **חומצה ממיסה** אבן, **אש** שורפת עץ והופכת מים לאדים.

רץ בדפדפן — פשוט לינק. אפשר גם "הוסף למסך הבית" ב-iPhone והוא מרגיש כמו אפליקציה.

## איך מפעילים

### על ה-iPhone (הכי פשוט)
1. אחרי שמפעילים **GitHub Pages** (ראה למטה) — פותחים את הלינק ב-Safari.
2. לוחצים על כפתור השיתוף ⬆️ → **הוסף למסך הבית**.
3. עכשיו יש אייקון של המשחק על המסך, כמו אפליקציה אמיתית.

### מקומית על מחשב
פשוט פותחים את `index.html` בדפדפן. או משרת מקומי:
```bash
python3 -m http.server 8000
# ואז נכנסים ל- http://localhost:8000
```

## איך מפעילים GitHub Pages (חד־פעמי, מייצר לינק)
1. נכנסים ל-repo ב-GitHub → **Settings** → **Pages**.
2. תחת *Source* בוחרים את הענף (branch) שבו נמצא `index.html` ואת התיקייה `/ (root)`.
3. שומרים. אחרי דקה-שתיים מקבלים כתובת כמו:
   `https://<שם-המשתמש>.github.io/joni-new-mobile-game/`

## שליטה
- **גרירה על המסך** — מציירים בחומר הנבחר.
- **מברשת** — גודל המכחול.
- **שמור / טען** — נשמר בדפדפן (localStorage), נשאר גם אחרי סגירה.
  יש גם שמירה אוטומטית כל 10 שניות.

## מבנה הקוד
- `index.html` — כל המשחק (הכל בקובץ אחד, קל לקרוא ולערוך). המנוע
  (`step`, `updatePowder`, `updateLiquid`, `updateGas`) עובר על רשת התאים
  ומזיז חומרים לפי כובד וצפיפות.
- `manifest.webmanifest` + `icon.png` — הופכים אותו לאפליקציה שאפשר להתקין.

## מה הלאה (רעיונות להמשך)
- מערכת **נקודות** ופתיחת חומרים מיוחדים (calcite, עצמות, צדפים…).
- **מתכונים**: לשלב חומרים ליצירת חומרים חדשים (חומצה על אבן → …).
- עוד חומרים: זרעים/צמחים שגדלים, לבה, קרח, גז נפיץ.
- בורא-חומרים: להרכיב חומר חדש מאפס עם תכונות משלו.
- חידות / אתגרים כמו במשחק המקורי.
