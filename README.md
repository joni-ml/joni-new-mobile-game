# שרידות — joni-new-mobile-game

**המשחק כולו נמצא בקובץ אחד: [`index.html`](index.html)**

זהו כל המשחק — HTML, CSS ו-JavaScript ביחד. אין קבצים אחרים לערוך.

## איך לשחק

- **בדפדפן:** פותחים את `index.html`
- **בטלפון:** דרך GitHub Pages, או מקיצור דרך (Shortcut) שטוען את הקובץ

## מבטים

למשחק יש שני מבטים על אותו עולם:

- **מבט מלמעלה** — התצוגה המקורית
- **גוף ראשון (תלת־מימד)** — raycaster; גרירה על המסך מסובבת את המצלמה ומסתכלת למעלה/למטה

מחליפים ביניהם מההגדרות (⚙️).

## הערה למי שעורך

אם אתם מוצאים עותק ישן בשם `main.py` בענף אחר — הוא הוסר. `index.html` הוא הקובץ היחיד.
