# 🏖️ ארגז חול (Sandbox)

משחק **ארגז חול** לניסויים בפיזיקה וגילוי חומרים — בהשראת *The Sandbox*,
אבל **בלי לקנות כלום בכסף**: כל חומר נפתח דרך ניסוי, שילוב וגילוי.

מתחילים עם 3 חומרי יסוד בלבד — 💧 **מים**, 🟫 **אדמה**, 🪨 **אבן** — וכל השאר
מתגלה תוך כדי משחק: מחברים חומרים, מגדלים עצים, ומגלים אש, אדים, זכוכית ועוד.

רץ בדפדפן — פשוט לינק. אפשר גם "הוסף למסך הבית" ב-iPhone והוא מרגיש כמו אפליקציה.

## איך משחקים
- **גוררים על המסך** כדי לצייר בחומר הנבחר.
- **המדריך** 🧑‍🔬 למעלה נותן משימות: מה לנסות עכשיו, ומה הבא.
- כל **גילוי** חדש נפתח בלוח החומרים למטה, ומקבלים נקודות ⭐.
- **📖 פדיה** — רשימת כל החומרים: מה שגילית (עם המתכון) ומה שעוד לא (❓ + רמז).

## עץ הגילויים (מתכונים)
| חומר | איך מגלים |
|------|-----------|
| 🟤 בוץ | 💧 מים + 🟫 אדמה |
| 🌱 נבט | בוץ לח שנח על הקרקע מצמיח נבט |
| 🌳 עץ | הנבט גדל כלפי מעלה |
| 🍃 עלה | גדל על העץ בזמן הגדילה |
| 🌸 פרח | עץ בוגר מוציא פרח בראש |
| 🌰 זרע-עץ / זרע-פרח | נופלים מהפרח — שותלים אותם בבוץ לגדל עוד |
| 🔥 אש | המקום לוהט — עץ נדלק מעצמו (וכך מגלים אש) |
| 💨 אדים | 🔥 אש + 💧 מים |
| 🏖️ חול | מים שוחקים 🪨 אבן |
| 🔮 זכוכית | 🏖️ חול + 🔥 אש |
| 🌋 לבה | 🪨 אבן + 🔥 אש (נמסה) — ולבה + מים חוזרת לאבן |
| 🪵 אפר | מה שנשאר משריפה — אפר + מים = אדמה פורייה |

## שמירה
נשמר בדפדפן (localStorage) — נשאר גם אחרי סגירה. שמירה ידנית 💾 + אוטומטית
כל 10 שניות. נשמרים גם החומרים שגילית והניקוד.

## איך מפעילים
### על מחשב (מקומית)
פותחים את `index.html` בדפדפן, או:
```bash
python3 -m http.server 8000   # ואז http://localhost:8000
```
### לינק חינמי (GitHub Pages)
Settings → Pages → Source: הענף עם `index.html` + `/(root)` → Save.
מקבלים כתובת כמו `https://<user>.github.io/joni-new-mobile-game/`.

## מבנה הקוד (`index.html`, קובץ אחד, קל לקרוא)
- **המנוע** — `step()` עובר על רשת התאים; `movePowder/Liquid/Gas` = פיזיקה.
- **התגובות** — `react()` וכל פונקציות ה-`reactX` = החיבורים בין חומרים.
- **הצמיחה** — `reactMud`, `growSprout`, `reactSeed`, `reactFlower`.
- **הגילויים** — `discover()` פותח חומר, מוסיף ללוח ולפדיה, נותן ניקוד.
- **המשימות** — מערך `MISSIONS` + `checkMissions()`.

## מה הלאה (רעיונות)
- חומרים מתקדמים: חומצה, קרח, מתכת, זרעים מיוחדים.
- מזג אוויר / שמש / טמפרטורה שמשפיעה על הגדילה.
- אתגרים וחידות ("גדל יער", "הכן זכוכית").
