# 🏖️ ארגז חול (Sandbox)

משחק **ארגז חול** לניסויים בפיזיקה — עם **סימולציה תרמית אמיתית**: לכל פיקסל
יש טמפרטורה משלו, החום עובר בין חומרים, והחומרים משתנים לפי חום (המסה,
הקפאה, רתיחה). בהשראת *The Sandbox* / *The Powder Toy*, אבל **בלי לקנות כלום
בכסף** — כל חומר נפתח דרך ניסוי וגילוי.

מתחילים עם 3 חומרי יסוד — 💧 **מים**, 🟫 **אדמה**, 🪨 **אבן** — וכל השאר מתגלה.

## איך משחקים
- **גוררים על המסך** כדי לצייר בחומר הנבחר.
- **🔥 מברשת חום / ❄️ מברשת קור** — מחממים או מקררים אזור (בלי לשנות חומר).
  ככה ממיסים, מקפיאים ומדליקים דברים.
- **המדריך** 🧑‍🔬 נותן משימות, וכל **גילוי** נפתח בלוח ובפדיה 📖 (עם המתכון).
- **מהירות** — סליידר להאטה/האצה של הסימולציה.

## הפיזיקה התרמית (°C)
| חומר | מה קורה |
|------|---------|
| 💧 מים | מעל **100°** → 💨 אדים · מתחת ל-**0°** → 🧊 קרח |
| 🧊 קרח | מתחמם מעל 0° → חוזר למים |
| 💨 אדים | מתקרר מתחת ל-96° → מתעבה חזרה למים |
| 🪨 אבן | מעל **1100°** → 🌋 לבה. גם **נופלת ושוקעת** במים (כובד) |
| 🌋 לבה | מתקררת מתחת ל-**600°** → בזלת (אבן). ליד מים: נותנת חום למים → אדים, ומתקררת עד שהיא מתמצקת |
| 🏖️ חול | מעל **1400°** → 🔮 זכוכית |
| 🌳 עץ/עלה/פרח | מעל **300°** → 🔥 נדלק |
| 🔥 אש | חמה (~760°), מדליקה שכנים, ומשאירה 🪵 אפר |

## עץ הגילויים (מתכונים לא-תרמיים)
| חומר | איך |
|------|-----|
| 🟤 בוץ | 💧 מים + 🟫 אדמה |
| 🌱→🌳 נבט/עץ | בוץ לח על הקרקע מצמיח נבט שגדל לעץ |
| 🍃🌸 עלה/פרח | גדלים על העץ הבוגר |
| 🌰 זרעים | נופלים מהפרח — שותלים בבוץ לגדל עוד |
| 🏖️ חול | מים שוחקים אבן |
| 🪵 אפר | נשאר משריפה · אפר + מים = אדמה |

## שמירה
נשמר בדפדפן (localStorage): החומרים שגילית, הניקוד, והעולם. שמירה ידנית 💾
+ אוטומטית כל 10 שניות.

## מבנה הקוד (`index.html`)
- **מנוע תנועה** — `movePowder/Liquid/Solid/Gas` (כובד, צפיפות).
- **מנוע חום** — `thermal()`: הולכת חום בין תאים + `checkPhase()` למעברי פאזה.
- **תגובות/צמיחה** — `react*`, `growSprout`.
- **גילוי/משימות/פדיה** — `discover`, `MISSIONS`, `buildPedia`.

## מה הלאה (רעיונות)
- עוד חומרים: חומצה, מתכת (מוליכה חום מהר), נפט, קרח יבש.
- מזג אוויר / שמש שמשפיעים על הטמפרטורה.
- אתגרים: "הפוך אבן לזכוכית", "הקפא אגם".
