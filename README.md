# אטומים — סימולטור פיזיקה תאי דו-ממדי

`index.html` — משחק/סימולטור עצמאי (קובץ בודד, ללא תלויות) שרץ בדפדפן ובמובייל.
פותחים את `index.html` בדפדפן וזהו.

## ארכיטקטורה: "פיזיקה קודם"
כל פיקסל הוא **תא** בעל חומר ואנרגיה תרמית. המצב (מוצק/נוזל/גז) **נגזר אוטומטית**
מהטמפרטורה מול נקודות ההיתוך/רתיחה של החומר — לא מקודד ידנית. חומר מוגדר אך ורק
ע"י תכונות אמיתיות: היתוך, רתיחה, צפיפות, משקל מולקולרי, קיבול חום סגולי, חום כמוס
ומוליכות חום.

## מה מומש
**חום ותנועה**
- תורת התנועה הקינטית: רעד אטום ∝ √(T/משקל־מולקולרי).
- אנרגיה נאגרת בכל תא; חום כמוס (Lf/Lv) מונע רתיחה/המסה מיידית.
- הולכת חום ברדיוס שכנים מתכוונן (1–4) עם משקלים מנורמלים וחסם יציבות CFL (κ≤0.5).
- קרינת חום (Stefan–Boltzmann, T⁴), הסעה (convection), ציפה, כבידה, זרימת נוזלים.

**תצוגה** (כפתור 🎨)
1. חומר · 2. מפת חום (כחול־קר → לבן־חם) · 3. אטומים — בזום כל אטום מצויר בנפרד ורוטט
   לפי מהירותו; ספרייט אטום נוצר פרוצדורלית מצבע החומר.

**כימיה** — בעירה (צורכת חמצן), חלודה, חומצה+מתכת→מימן, המסה, מימן+חמצן→מים.
~24 חומרים עם ערכים מדעיים אמיתיים.

**ביולוגיה** — זרע→צמח→עלים→פוטוסינתזה (CO₂+אור+מים→חמצן), חיידק שמתחלק, ריקבון→אדמה.
תנאי סף לחיים: מים + טווח טמפרטורה + אור.
